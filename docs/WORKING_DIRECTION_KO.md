# 작업 기준과 향후 사내 이전

2026-10-30 사용자 결정

- KPI 코드 작업 기준: https://github.com/yomimon-parkjeong/meta-ads-kpi
- 현재 테스트 사이트: https://meta-ads-kpi.parkubwin8318.workers.dev/login
- 사이트를 다시 찾는 요청이 오면 위 주소를 안내한다. 정기 알림 요청은 아니다.
- 토큰, 비밀번호, API 인증정보, 실제 광고 성과 데이터를 공개 코드에 넣지 않는다. 공개 저장소는 소스만 관리한다.
- 테스트 단계에서는 사용자가 로그인 후 광고계정과 Meta 토큰을 직접 입력한다. API는 조회만 사용하며 기존 텔레그램 브리핑과 분리한다.
- 사내 데이터로 이관할 때 PHP 서버 버전으로 전환한다. PHP 서버가 사내 DB와 서버 환경변수 또는 비밀값 저장소를 통해 인증정보와 데이터를 연결하도록 설계한다. 인증정보를 PHP 소스나 Git에 하드코딩하지 않는다.
- 자동 연결은 PHP 파일 확장자 변경만으로 구현되지 않는다. 서버 인증, 읽기 전용 Meta 수집, 페이지 처리, 데이터 정규화, 사내 DB 저장 및 접근 제어를 이관하고 실제 데이터로 정합성을 검증해야 한다.
- 현재 PHP 전환과 사내 DB 연결은 구현되지 않았다. 테스트 사이트의 실적 조회도 실제 계정 연결 후 검증이 필요하다.
- 기존 Cloudflare 배포와 로그인 보호를 해제하거나 삭제하라는 요청은 아니다. 기존 텔레그램 예약을 변경하지 않는다.

## 회사 임시 작업과 USB

회사 PC의 10월 26일 백업을 기준으로 클라우드용 KPI를 준비했다. 이후 원본 USB의 변경사항은 사용자가 검토하고, 월요일 작업 종료 전에 회사 임시 작업과 GitHub 최신본을 비교해 USB에 반영·백업한다. 회사 임시 폴더의 옛 ZIP은 최신 GitHub 커밋과 일치하지 않을 수 있으므로 그대로 최신본으로 취급하지 않는다.
