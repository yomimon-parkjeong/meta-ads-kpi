# 메타 광고 KPI

10월 26일 로컬 KPI를 바탕으로 한 Cloudflare Workers 배포용 소스입니다. 기존 텔레그램 브리핑은 포함하지 않습니다. GitHub Pages는 켜지 마세요. 로그인은 Cloudflare Worker에서 처리해야 합니다.

## 배포
Cloudflare Workers에서 GitHub 저장소 `yomimon-parkjeong/meta-ads-kpi`를 연결합니다. 프로젝트 루트는 저장소 루트, 배포 명령은 `npx wrangler deploy`입니다. 무료 Workers 플랜으로 시작합니다. Wrangler 설정의 ASSETS 및 LOGIN_LIMITER 바인딩을 유지해야 합니다.

Cloudflare Worker의 런타임 Secrets에 아래 두 값을 직접 입력하세요. GitHub 파일, 채팅, 일반 환경변수 또는 빌드 로그에 비밀번호를 기록하지 마세요.

- `DASHBOARD_PASSWORD`: 공용 비밀번호, 최소 12자
- `SESSION_SECRET`: 세션 암호화용 무작위 값, 최소 32자

비밀값 또는 로그인 제한 바인딩이 없으면 화면은 503으로 차단됩니다. 로그인 후 광고 계정 번호와 Meta 토큰을 입력합니다. 토큰은 Worker가 검증하고 암호화한 HttpOnly 쿠키에 세션과 함께 보관합니다. 영구 DB 저장은 하지 않으며, 원문 토큰은 JavaScript에서 읽을 수 없습니다. 세션은 8시간, 비밀번호 또는 암호화 키 교체 시 기존 세션은 무효가 됩니다. 로그아웃은 현재 브라우저 쿠키를 삭제하며 이미 탈취된 세션을 개별 철회하는 기능은 없습니다.

## 데이터
실제 광고 데이터나 토큰은 저장소에 없습니다. Meta에 읽기 전용 요청만 하며, 한국시간 광고계정의 어제까지 3/7/30일 및 직전 기간, 60일 소재 이력과 7일 계정 일별 지표를 조회합니다. Meta 보고 지연과 과거 귀속 수정이 있을 수 있으므로 실시간 확정 매출을 뜻하지 않습니다. 조회 도중 누락·권한·만료·페이지 오류가 나면 화면 표시를 중단하며 과거 스냅샷이나 가상 데이터로 대체하지 않습니다. 대량 조회는 수 분 걸리거나 Meta 호출 제한에 걸릴 수 있습니다. 조회 결과는 열린 브라우저 메모리에서만 분석합니다.

## 검증 상태
소스 문법 검사와 공개 대상 파일 점검을 완료했습니다. 실제 Cloudflare 배포, 로그인·로그아웃·세션 만료·잘못된 비밀번호, 원본 우회 접근 차단, Meta 실제 조회와 기존 로컬 결과의 정합성, 모바일 화면 및 무료 플랜 CPU 한도는 아직 검증 전입니다. 따라서 이 단계는 운영 검증 전 코드이며 검증 완료를 뜻하지 않습니다. 가상 광고 데이터는 사용하지 않았습니다.

데이터 접근은 수동 로그인 세션만 지원합니다. 텔레그램 자동 실행을 위한 서버 간 인증이나 연동은 아직 없으며 별도 검토가 필요합니다. 예산·예약 화면은 검토용 모의안만 만들고 실제 광고 설정을 변경하지 않습니다.
